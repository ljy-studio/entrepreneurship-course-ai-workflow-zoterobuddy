# 创业管理理论与前沿课程项目初始化工作流包

这是供厦门大学管理学院企业管理系创业学专业同学使用的可移交工作流包。它包含渐进式披露的 `SKILL.md`、可复制启动提示词、使用指南、工作流与格式参考文件，以及去除个人信息的周度作业模板。

## 交给 Agent 使用

1. 将本 ZIP 解压，或把解压后的整个文件夹发送给 Agent。
2. 如果 Agent 支持 Skill，让它读取 `SKILL.md` 并按其中链接按需读取参考文件；这不会自动安装 Skill。
3. 如果 Agent 不支持 Skill，发送 `启动提示词.md` 的内容，并附上本包中它需要使用的参考文件和空白模板。
4. 按 `使用指南.md` 完成初始化。初始化完成后，每周作业均新建一个对话，并通过当周文件延续上下文。

## 目录

- `SKILL.md`：项目初始化与每周工作流的入口。
- `启动提示词.md`：不支持 Skill 的 Agent 可直接使用的完整提示。
- `使用指南.md`：同学的操作说明，包含每周新建对话的要求。
- `references/`：课程默认信息、设置流程、周度研讨、文献工具、版式规范和 AI 使用评价。
- `assets/`：可复制并填写的空白周度 DOCX/PDF 模板。

课程与授课教师信息为固定默认值；学生个人信息须由使用者自行填写。AI 技巧评价是可选的学习反思模块，不代表课程官方评分标准。
