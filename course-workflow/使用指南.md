# 工作流包使用指南

## 这是什么

本包帮助课程同学让 Agent 初始化一套可持续使用的课程作业工作区，并按周完成文献准备、研讨、记录和文档交付。课程项目规则放在生成的项目文件里，项目文件负责延续上下文；每周对话保持隔离。

## 第一次使用：初始化项目

1. 将 ZIP 解压到准备存放课程项目的位置，或直接把 ZIP/文件夹发送给 Agent。
2. 若 Agent 支持 Skill，要求它读取包中的 `SKILL.md`，并按需打开 `references/` 内的文件；无需安装到个人 Skill 目录。
3. 若 Agent 不支持 Skill，将 `启动提示词.md` 发给它，并附上 `SKILL.md`、相关参考文件和空白作业模板。
4. 告诉 Agent 你的姓名、学号、年级、项目目录、是否需要 Git、当前周次与教师作业要求。不要把示例题当成本周真实题目。
5. 让 Agent 先检查目录和已有文件，说明计划与将新增的内容，再创建项目说明、约束、工作流、格式规则、模板、`.tmp` 和当前周文件夹。对于冲突文件，应保留已有内容并说明处理方法。
6. 初始化完成后，检查 Agent 给出的文件清单、目录路径和使用说明。确认封面个人字段仍可修改，正式教师要求优先于包内默认版式。

## 每周使用：新建独立对话

**每周作业都新建一个对话/线程。** 同一周的多个题目和主题可以在这个新对话中按顺序研讨；不要沿用上一周的对话，以免不同周次题目、文献和聊天上下文混在一起。

开始新对话时：

1. 在同一项目/工作区中新建对话，标题可用 `第N周课程研讨｜题目关键词`。
2. 告诉 Agent 这是第 N 周任务，提供教师原题、截止日期、既有讲义和额外要求。
3. 让 Agent 读取项目的 README、周度工作流和版式规范，再查看当周 `00_本周题目与材料.md`。按需附上相关文献或笔记，不必复制上一周完整聊天记录。
4. 让 Agent 在本周目录保存文献核验和研讨记录。对话中逐主题讨论；每个主题由你确认结束后，才进入下一主题。
5. 所有主题结束后，再明确授权制作最终成果。提交前检查 DOCX/PDF、引文、参考文献、图表和文档版面。

可直接在新对话中发送：

> 这是第【N】周创业管理理论与前沿课程任务。请先读取本项目 README、周度工作流、提问与追问规则和版式规范，再检查 `第【N】周` 目录及我提供的题目和材料。请按项目约定优先检索可用的本地 Zotero；根据实际可用工具处理文献，记录来源与核验状态。然后依题目顺序开始研讨，回应我的观点后自适应提出一个具体追问。讨论充分时先总结并询问我是否确认结束当前主题；未经确认不切换主题。未获得我对最终成果的明确授权前，不制作最终 DOCX/PDF。请将过程材料保存在当周目录，临时脚本和预览放在 `.tmp`。

## 工具缺失时

Agent 应先检测当前环境是否可用 Zotero/Zotero Buddy、LibreOffice 和 Office CLI。若有缺失，应列出具体缺项并询问你是否需要帮助安装；同意前不下载或安装。拒绝安装时，Agent 需说明对文献管理、PDF 导出或 Office 自动化检查的影响，并使用可用替代方式或标记未能完成的检查。

## Skill 生命周期

本包可作为普通文件交给 Agent 使用，不会自行安装到个人环境。若你选择自行安装或启用 Skill，由你决定是否保留；初始化完成后不需要自动卸载。项目中生成的工作流和模板继续留在课程项目里。
