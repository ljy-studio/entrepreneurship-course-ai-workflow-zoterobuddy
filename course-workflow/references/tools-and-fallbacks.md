# 工具检测、安装选择与替代路径

## 先检测再询问

开始项目初始化或文档工作流前，检查当前环境中是否可使用：

1. **Zotero 与 Zotero Buddy（或其他可访问本地库的接口）**：分别检查桌面程序/本地库与 Agent 的连接能力。
2. **LibreOffice**：检查 Writer/命令行转换能力是否可用于 DOCX 到 PDF 导出和渲染复核。
3. **Office CLI（`officecli`）**：检查是否可用于脚本化读取、查询或编辑 DOCX/XLSX/PPTX。它与 LibreOffice 是不同工具，不能互相替代所有能力。

根据操作系统使用只读的命令或应用清单检测；若 Agent 没有环境访问能力，向使用者询问或请其运行检测命令。不要把本机检测结果当成别人的环境状态。

## 缺失时的询问

汇总缺失工具及其用途，询问使用者是否希望 Agent 帮助安装。可一次询问多项，但须让使用者能分别同意或拒绝。说明将使用的官方来源/包管理器、可能需要的管理员权限和具体变更。用户明确同意后才安装；如来源不可信、需要接受新许可/订阅、权限异常或无法安全确认安装方式，停下来说明情况。

不自动安装、升级、配置个人账户、修改安全设置，也不自动卸载 Skill 或其他软件。使用者拒绝时，继续当前可完成的工作，并说明实际受影响的步骤。

## 拒绝安装时的影响与替代方式

- **没有 Zotero/Zotero Buddy：** 无法检索、去重、导入、分类或给本地 Zotero 文献打标签。可用公开稳定来源核验书目，维护手动文献表；不得称为本地命中或已入库。
- **没有 LibreOffice：** Agent 可能仍能创建 DOCX，但若没有其他 PDF 转换/渲染能力，就无法可靠完成批量导出和逐页版面复核。可改用已有的 Microsoft Word/WPS 导出并请使用者检查，或把该复核标为未完成。
- **没有 Office CLI：** 无法使用该 CLI 对 Office 文件进行结构化批量检查或编辑。可使用 Agent 当前可用的文档库、Word/LibreOffice 界面或人工检查；需报告替代方法及限制。LibreOffice 在场时仍可转换文件，但不等价于 Office CLI 的结构化操作。

缺少某工具不应阻断其他可完成步骤。每个交付物注明哪些检查实际完成、哪些因工具缺失未能完成。
