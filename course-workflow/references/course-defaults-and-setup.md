# 课程默认信息与项目初始化

## 固定课程信息

- 学校：厦门大学
- 学院：管理学院
- 系：企业管理系
- 专业：创业学
- 课程：创业管理理论与前沿
- 授课教师：木志荣教授
- 学生姓名、学号、年级：由每位使用者填写；不从模板作者或其他文件推断。

课程信息与个人信息必须分开记录。封面只填使用者本人明确提供的身份信息。

## 课程规则与推荐默认值

把教师/学院明确要求、使用者偏好和本包建议分别标注。教师发布的正式要求或模板优先。

- 工作区默认只创建当前正在处理的 `第N周`，不预建整个学期的周目录。
- `.tmp` 用于临时脚本、缓存、渲染预览和中间文件。
- 不默认初始化 Git；先检查现状，再由使用者选择。
- 题目短标题便于辨认；提交文件按 `第N周-姓名-题目短标题.docx/.pdf` 命名。保留修订版时在末尾追加一致版本号，如 `-v01`。
- 正文引注默认使用 GB/T 7714—2015 顺序编码制；若教师指定其他体例，按指定要求执行。
- AI 使用过程评价可作为个人反思模块，不宣称为教师的官方评分标准。

## 初始化步骤

1. 检查目标目录、已有说明、模板、版本和文件状态；遵守已有项目约定。
2. 记录课程、使用者信息、周常输入/输出、截止日期、引用要求、工具可用性、格式、授权节点、命名与版本规则。
3. 只询问影响目录或交付的重要未知；将其余合理默认值写明。
4. 计划确认后创建或补充 README、项目约束与规范、周度工作流、版式要求、周度模板和 `.tmp`。先评估已有文件，再避免覆盖。
5. 只建立当前周所需目录与记录文件；不伪造教师题目、材料、文献和对话。
6. 初始化完成后，在对话中列出实际创建的文件与路径、尚需补充的信息和后续周度使用方法；明确每周需新建一个对话。

## 推荐目录

```text
课程项目/
├─ README.md
├─ 项目约束与规范.md
├─ 周度工作流.md
├─ 版式与格式规范.md
├─ AI技巧评价.md                 # 可选，依教师/学生需求
├─ 周度作业模板.docx / .pdf
├─ 第N周/                         # 仅在处理该周时创建
│  ├─ 00_本周题目与材料.md
│  ├─ 01_文献检索与核验.md
│  ├─ 02_研讨聊天记录.md
│  └─ 图示/                       # 按需创建
└─ .tmp/                          # 临时文件
```

## 初始化后须交代的对话使用规则

- 每周新建一个 Agent 对话/线程，标题包含周次和关键词。
- 同一周的多个主题在该周对话内顺序研讨；用当周文件记录状态和结论。
- 新对话开场重新提供当周原题、教师新增要求和必要附件，并让 Agent 读取项目规则及当周记录文件。
- 不复制上一周整段聊天作为默认上下文；确有必要时，只提供相关概要或已核验文献线索。
- 当前 Agent 无法访问项目目录时，使用者在新对话附上 README、工作流和当周材料。
